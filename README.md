## 💡 Filosofia de Código

> *"Código limpo não é sobre ser conciso, é sobre ser claro. Bom design não é sobre ser bonito, é sobre funcionar. Meu trabalho é onde essas duas verdades se encontram."*

**Meus princípios:**
- ✅ Código semântico e acessível por padrão
- ✅ Componentes pensados para escala, não só para hoje
- ✅ Comentários que explicam o "por quê", não o "o quê"
- ✅ Design systems > designs isolados
- ✅ Performance é feature, não afterthought
